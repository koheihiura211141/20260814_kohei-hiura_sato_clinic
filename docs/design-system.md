# 佐藤医院 Webサイト デザインシステム

この文書は、現在のPC版デザインの統一と、将来のレスポンシブ化を安全に進めるためのデザインルールです。

## 1. デザイン方針

キーワード：

- 清潔感
- 誠実さ
- 安心感
- 親しみやすさ
- 地域密着

派手さよりも、情報の見つけやすさ・読みやすさを優先する。

## 2. カラーパレット

現在のCSSを基準に、主要色を以下の5色として扱う。

| 用途 | 色 | HEX |
|---|---|---|
| ベース背景 | ホワイト | `#FFFFFF` |
| 淡い背景 | ミント | `#EAF6F0` |
| メインアクセント | グリーン | `#078F64` |
| 濃いアクセント | ディープグリーン | `#067858` |
| 基本文字 | ブラック寄り | `#111111` |

補助色として既存CSSにある `#55A889`、`#65C3A3`、`#DDF3EA` 等は、既存コンポーネントとの整合を保つ範囲で使用可。

### カラー運用

- 大面積の背景は白または淡いミントを基本とする。
- 濃いグリーンは見出し、Q/Aマーカー、アクセント、ボタン等に限定する。
- 本文は黒〜濃いグレーで十分なコントラストを確保する。
- 新規に高彩度の赤・紫・蛍光色などを主役として追加しない。

## 3. タイポグラフィ

現在の基本フォント：

```css
font-family: "Noto Sans JP", "Noto Sans CJK JP", "Yu Gothic", sans-serif;
```

ヒーローのコピーのみ、明朝系の雰囲気を利用している。

### 文字ルール

- 本文は読みやすさを最優先する。
- 長文は適切な行間を保つ。
- 見出しは太さとサイズで階層を明確にする。
- 文字を画像化しない。
- 将来のスマホ対応を考え、修正時に不要な `<br>` を増やさない。
- 現在ある `<br>` を別修正のついでに勝手に削除しない。

## 4. レイアウト

### 現在

- PC版は1440pxのFigmaデザインを基準に調整済み。
- 現行CSSには固定幅・固定高が多く含まれている。
- 現段階では見た目を壊す大規模な可変化を行わない。

### 将来のレスポンシブ対応

レスポンシブ化は別工程で行う。具体的なブレークポイントは、その工程で実画面を確認して決定する。

その際の基本方針：

- `width: 1440px` / `min-width: 1440px` 依存を段階的に解消する。
- コンテンツ幅は `max-width` と左右余白で管理する。
- 画像は必要に応じて `max-width: 100%`、`object-fit` を利用する。
- 横並びカードは狭い画面では縦並びを検討する。
- 診療時間表は文字を極端に縮小せず、必要なら横スクロール等を検討する。
- ヘッダーナビはスマホでの表示方式を別途設計する。
- フォントサイズは可読性を落とさない。

## 5. 主要コンポーネント

### ヘッダー

- 左：佐藤医院ロゴ
- 右：グローバルナビ
- 白背景
- 情報量は多くても、視認性を優先する

### ヒーロー

- 支給写真を大きく使用
- 「地域に根ざした医療」を主コピーとする
- 清潔感を損なう派手な加工を追加しない

### 診療時間表

- 表形式を維持
- 診療・休診が一目で分かること
- 高齢者も読める文字サイズを意識

### セクション見出し

- 中央見出し＋左右線の既存スタイルを基本とする
- 新規セクションも既存のトーンに合わせる

### 診療内容・スタッフカード

- 写真と説明を組み合わせる
- 青・緑系の医療アイコンを使用
- カード間の余白を十分に確保
- 新規アイコンは既存アイコンと線・色・情報量を合わせる

### FAQ

FAQを再実装する場合の基本：

- QとAを一目で区別できる色・マーカーにする
- Q：濃いグリーン系
- A：淡いグリーン系
- 派手すぎない
- 回答本文を小さくしすぎない

### フッター

- ロゴは中央配置
- ロゴ下に教材用の断り書き
- 最下部に淡いグリーンのコピーライト帯
- 断り書きは削除しない

## 6. 画像ルール

- 原則として `assets/images/` 内の支給画像のみを使用する。
- 画像の差し替えは明示指示がある場合のみ行う。
- `object-position` はFigmaとの見た目合わせで細かく調整されている箇所があるため、無関係な修正で変更しない。
- 画像ファイル名を変更する場合は、参照先をすべて同時に更新する。

## 7. CSS編集ルール

- 既存CSSはFigma参照に合わせた微調整が積み重なっているため、全体の書き直しは禁止。
- 同じセレクタが複数回登場していても、別依頼のついでに整理しない。
- 修正はできるだけ対象セレクタに限定する。
- 不要な `!important` を追加しない。
- 新しい固定高さ・絶対配置を安易に追加しない。
- 将来レスポンシブ化するときは、まず重複定義と固定寸法を段階的に整理してから行う。
