# 佐藤医院 Webサイト

## 概要

職業訓練の課題として制作した、架空の医院のWebサイトです。患者が診療時間や診療内容、アクセス方法などを確認しやすいよう、情報を整理して掲載しました。

トップページのほか、お知らせ一覧・記事、診療内容、医院紹介、よくあるご質問のページを制作しています。

## 閲覧方法

リポジトリをダウンロードしてZIPファイルを展開し、展開したフォルダ内の `index.html` をブラウザで開くと閲覧できます。

※画像やスタイルを表示するため、`index.html` だけでなく、展開したフォルダ内のファイル・フォルダ構成を保ったままご覧ください。

## 使用技術

- HTML
- CSS
- JavaScript（ライブラリ不使用）
- Google Maps 埋め込み

## 実装した機能

- ページ内リンクと各ページへのナビゲーション
- モバイル向けドロワーメニュー
- 写真・診療内容・スタッフ紹介のカルーセル
- 院長挨拶文の表示切り替え
- お問い合わせフォームの入力チェックと確認画面
- Google Maps の埋め込み
- 画面幅に応じたレイアウト調整

## 工夫した点

医院のWebサイトとして清潔感や安心感が伝わるよう、白と淡いグリーンを基調にデザインしました。診療時間は表形式で示し、お知らせや診療内容は見出しやカードで整理することで、必要な情報を探しやすくしています。

スマートフォンなどの画面幅でも利用しやすいよう、ナビゲーションやカードの表示を調整しました。また、メニューやお問い合わせ画面の開閉、カルーセルの操作などにJavaScriptを使い、操作状態が分かる属性も設定しています。

## 制作上の補足

お問い合わせフォームは、入力内容の確認までを行うフロントエンドのデモです。実際にメールを送信するバックエンド機能は実装していません。

本サイトは職業訓練の学習用に制作した架空のサンプルサイトです。掲載している医院・人物・連絡先・所在地はすべて架空であり、実在のものとは関係ありません。
