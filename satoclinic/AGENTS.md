# AGENTS.md — 佐藤医院サイト AI作業ルール

このリポジトリをCodex / ChatGPTなどのAIが編集する場合、**作業開始前に必ずこのファイルと `docs/` 内のMarkdownを読むこと。**

## 読む順番

1. `AGENTS.md`
2. `docs/requirements.md`
3. `docs/specification.md`
4. `docs/design-system.md`
5. 修正対象の `index.html` / CSS / その他ファイル

## 最優先ルール

- ユーザーが指定した箇所以外は変更しない。
- 既存の見た目・文章・画像を、AIの判断で「より良く」変更しない。
- 掲載原稿は確定テキスト。原則として改変しない。
- 基本情報は `docs/specification.md` を参照する。
- 基本情報と現行実装が食い違う場合、勝手に直さず差異を報告する。
- 支給画像以外を勝手に追加しない。
- 大規模リファクタリング、フレームワーク導入、ビルド環境追加をしない。
- 1回の修正は最小差分とする。

## 現在の作業フェーズ

現在はPC版（1440px基準）を維持する段階。

**レスポンシブ対応は後工程。ユーザーから明示指示が出るまで実装しない。**

ただし、新規修正では将来のレスポンシブ化を不必要に難しくしないこと。

- 新しい固定幅・固定高を安易に増やさない。
- 新しい絶対配置を安易に増やさない。
- 既存のセマンティックなHTML構造を維持する。
- 画像やカードの構造を壊さない。

## HTML編集ルール

- `index.html` はGitHub Pages公開用としてルート直下に置く。
- CSS参照は `./assets/css/style.css`。
- 画像参照は `./assets/images/...`。
- 相対パスを使用する。
- `<meta name="robots" content="noindex, nofollow">` を削除しない。
- フッターの教材用断り書きを削除・改変しない。
- 文言変更はユーザーが明示した範囲のみ。
- アクセシビリティ上必要な `alt`、`aria-label` を無関係な作業で削除しない。

## CSS編集ルール

- `assets/css/style.css` はFigmaとの見た目合わせの履歴があるため、全体を書き直さない。
- 対象箇所だけを修正する。
- 既存の `object-position` やサイズ指定を、理由なく変更しない。
- 無関係な重複CSSの整理・圧縮・並べ替えをしない。
- 新しい色を追加する場合は `docs/design-system.md` を確認する。

## JavaScript編集ルール

- 現在のサイトはJavaScriptを必要としていない。
- `assets/js/script.js` は将来用の予約ファイル。
- 必要性がない限りJavaScriptを追加・読み込みしない。

## 画像ルール

- 使用可能な画像は原則 `assets/images/` 内の支給素材。
- 新しい外部画像を勝手にダウンロード・生成・追加しない。
- 画像名変更時は参照切れを発生させない。

## 作業前チェック

修正前に以下を確認する。

1. ユーザーが変更を求めている範囲
2. 関連する要件・原稿
3. 現在のHTML/CSS実装
4. 修正による他セクションへの影響

## 作業後チェック

最低限、以下を確認する。

1. 指定箇所以外が変わっていないか
2. HTMLから参照しているCSS・画像が存在するか
3. GitHub Pagesで使えないローカル絶対パスが入っていないか
4. `noindex, nofollow` が残っているか
5. フッターの教材用断り書きが残っているか
6. 既存のPC版レイアウトを壊していないか

## 既知の差異

`docs/specification.md` の「現在の実装で確認済みの差異・注意点」を参照すること。

差異があっても、今回の依頼と無関係なら修正しない。

## 判断に迷う場合

仕様書にない変更や、複数の解釈が可能な変更は実装せず、ユーザーへ確認する。
